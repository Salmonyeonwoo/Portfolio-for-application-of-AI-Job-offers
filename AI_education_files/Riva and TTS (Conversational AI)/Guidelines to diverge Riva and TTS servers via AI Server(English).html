3. Technical Challenges & Solutions

3-1. Solving GPU Resource Allocation for Docker Containers

Challenge: While Riva requires GPU acceleration, correctly linking and utilizing GPU resources within a Docker environment involves complex configuration.

Solution: By correctly understanding and applying `nvidia-container-toolkit` settings and Docker commands (e.g., `--gpus all`), an environment was built where Riva containers can fully utilize the GPU. This avoided complex environment dependency issues and ensured rapid deployment.

3-2. Implementing Real-Time Streaming via gRPC

Challenge: Riva uses gRPC as its default protocol for high performance. Specifically, ASR must handle real-time voice streaming, requiring the implementation of bidirectional streaming on the client side.

Solution: Successfully developed streaming client logic using Python's `iterator` and `yield` keywords to continuously send audio chunks to the server while simultaneously receiving real-time ASR text results.
